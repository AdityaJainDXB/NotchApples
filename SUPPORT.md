# Getting help with Notch Apple

No GitHub account? Use the **[form on the website](https://adityajaindxb.github.io/NotchApples/support.html)**: no sign-in, it covers everything below, and it is posted here for you (licence and payment questions stay private). If nothing else works, email notchapples.support@gmail.com.

| I want to... | Go here |
|---|---|
| Report something broken | [New issue](https://github.com/AdityaJainDXB/NotchApples/issues/new/choose), pick Mac, Windows or Flight simulator |
| Suggest a feature | [New issue](https://github.com/AdityaJainDXB/NotchApples/issues/new/choose), "Suggest a feature" |
| Ask how something works | [Discussions, Q&A](https://github.com/AdityaJainDXB/NotchApples/discussions/categories/q-a) |
| Share my setup | [Discussions, Show and tell](https://github.com/AdityaJainDXB/NotchApples/discussions/categories/show-and-tell) |
| Updates and licence help | [Help or feedback](https://github.com/AdityaJainDXB/NotchApples/issues/new/choose) or the site chat at https://adityajaindxb.github.io/NotchApples/ |

## Before you write
- Update first: Mac uses the in-app updater (or `brew upgrade --cask notch-apple`), Windows uses the installer from the latest release.
- Include your app version and macOS or Windows version.
- Never post a licence key, access code or password. Redact screenshots.
- Telemetry is opt-in and anonymous. See the privacy page on the website.

Security problems: please do not open a public issue. Email notchapples.support@gmail.com.
