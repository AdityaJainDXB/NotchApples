**Printer Status**
- 🔑 **Sign in to Bambu without a password.** If you use Google, Apple or Facebook to sign in to Bambu, enter the same email in Printer Status and press **Email me a code instead**: Bambu emails a six-digit code and that is all you need. Like the rest of the account sign-in, this is based on what the community has documented and has been tested against a simulated Bambu, not a live account, so please tell us if it does not work for you (LAN Mode always does).

Windows 1.63.0 BETA has the same option.

Install: download the DMG below and drag Notch Apple to Applications, or `brew upgrade --cask notch-apple`.
