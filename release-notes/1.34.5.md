**New**
- 🔎 **Settings search finds features.** Type `windows` and Modules & Layout opens showing only the Windows feature, highlighted, with a **Show all features** button. Pane results still appear as before; pressing Return opens the feature first.
- 🎨 **A nicer Claude usage tab.** A ring for each limit (colour shows pace), a "Now / 30 days" switch, and Opus and Sonnet weekly bars when Claude reports them.
- 📊 **30-day history chart.** Your highest 5-hour and weekly point each day, kept on this Mac only. It fills in as the tab stays connected.
- 👥 **Several Claude accounts.** If Claude Code is signed in under more than one account, choose which one to show and see the others' limits at a glance. macOS asks once per account.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
