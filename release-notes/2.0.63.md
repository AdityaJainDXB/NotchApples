**Printer Status**
- 🖨️ **Find printers on my account.** After you sign in with your Bambu account, this button lists the printers on it again, using the saved sign-in, so you never have to sign out and in to pick up a printer. If you are signed in and have added none yet, the list appears by itself. Before, the list only existed while the Settings screen stayed open.

Windows 1.67.0 BETA has the same button.

Install: download the DMG below and drag Notch Apple to Applications, or `brew upgrade --cask notch-apple`.
