**Fixed**
- 📥 **Drag a file to the top centre of the screen and the notch opens for the drop**, whether it comes from a Finder window or the desktop. The earlier attempt (2.0.38) never fired, because macOS does not send mouse events to other apps while a drag is under way; the notch now watches the pointer and the drag clipboard instead.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
