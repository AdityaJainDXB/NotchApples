[required-update]

**New**
- ⬆️ **Required updates.** A release can now be marked as required: until you update, the open notch shows a single **Update now** screen (Settings and the menu bar still work, and nothing is blocked if GitHub can't be reached). It works with "Check for updates automatically" on.
- ✨ **After an update, a window lists the new things that are optional** (Dev Tools, Wellbeing, the Claude Code screen flash, ⌥A blackout) with a switch for each, once per update. Change them any time in Settings.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates. Choose **Update** or **Not now**, or turn automatic checks off.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
