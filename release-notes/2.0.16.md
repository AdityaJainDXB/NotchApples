**New**
- ⌨️ **⌥A now turns the keyboard backlight off too.** Press Option+A and both the screen and the keyboard light go to zero; press it again and both come back exactly as they were (including automatic keyboard brightness).
- 🔧 **Settings → Reset keyboard brightness.** If the backlight is ever stuck dark, this turns automatic brightness back on and restores a normal level.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates. Choose **Update** or **Skip for now**.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
