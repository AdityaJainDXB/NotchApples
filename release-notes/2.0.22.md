**New**
- 🔁 **Convert (Ultimate): turn any file into another kind.** Drop files on the new Convert tab (or click **Choose files**), check what each one is in **From**, pick what it should become in **To**, and click **Convert**. The result is saved next to the original and never over anything. Click **Open** or **Show** to find it.
  - **Pictures:** PNG, JPEG, HEIC, WebP, GIF, BMP, TIFF, ICO, SVG and AVIF to PNG, JPG, HEIC, GIF, BMP, TIFF, ICO, WebP or PDF. Several pictures can be **combined into one PDF**.
  - **PDF:** every page to a PNG or JPG, or the text to Word, RTF, a web page, Markdown or plain text.
  - **Documents:** Word, Pages, RTF, OpenDocument, web pages, Markdown and text to PDF, Word, RTF, a web page, Markdown, text or Pages.
  - **Presentations:** PowerPoint and Keynote to PDF, PowerPoint, Keynote, or a picture of every slide (through Keynote).
  - **Tables:** Excel, Numbers, CSV, TSV and JSON to Excel, CSV, JSON, TSV, a web page, PDF or Numbers.
  - **Audio and video:** MP3, M4A, WAV, FLAC, AIFF and CAF; MP4, MOV and M4V; the sound of a video on its own; a video as a GIF. Install FFmpeg (free) for MP3, Ogg, Opus, WebM, MKV and AVI too.
  - **Zip** any file or folder, or unzip one.
  - **Make them all** sets the same target for every file in the list. The tab shows which helpers this Mac has (Keynote / Pages / Numbers, LibreOffice, FFmpeg). When a file needs one, it says so and links to it.

Windows 1.38.0 BETA gets Convert too. On Windows, Office files go through Word, PowerPoint and Excel when they're installed (LibreOffice, free, when they aren't). PDF pages become pictures with Windows' own PDF reader. It also includes 1.37.0's Klick and Plane fixes.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
