**Fixed**
- ⌨️ **Klick (keyboard sounds) asks for the permission it needs.** After an update, some Macs stayed silent because macOS wants **Input Monitoring** as well as Accessibility for hearing keys in other apps. Klick now asks for both, shows which one is missing with a button for each, and explains how to reset a permission that looks on but doesn't work after an update (select Notch apple, press −, add it again).
- Klick no longer risks an error if the sound output is busy or changing (for example when headphones connect): it skips that click and carries on.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
