**New**
- 🏝 **A much bigger Plane map.** Four new airfields: **Seaside** on the southern plain, and **Coral Island**, **Palm Atoll** and **Lighthouse Cay** on hilly islands in the sea to the south. Each has a runway with markings and lights, a hangar, a windsock and a helipad.
- 🧭 **Start anywhere.** A **Start at** row in the Fly tab picks the airfield for Free Flight (helicopters start on that airfield's helipad). The screen shows the nearest airfield, its distance and which way to turn.

**Security and fixes (from a full code review)**
- Links like `notchapple://keepawake?minutes=…` could crash the app with a huge or invalid number.
- An unreadable saved-keys file could wipe every saved key; a copy is now kept first.
- A restored settings backup could change where your Home Assistant token is sent; those settings are no longer restored.
- PairDrop now limits file size and marks received files as downloaded, so macOS asks before opening an app or script.
- Plugins can no longer be set to refresh every second.
- Windows: backups no longer include tokens or printer codes, and a restored backup can't overwrite them; the web helper rejects look-alike local addresses and unsafe redirects; only data files can be saved to the temp folder; VPN profiles are stripped of lines that could run programs.

Windows 1.55.0 BETA gets the same map and the Windows fixes.

Install: download the DMG below and drag Notch Apple to Applications, or `brew upgrade --cask notch-apple`.
