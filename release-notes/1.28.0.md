**New**
- 🧩 **Choose and arrange your tabs by dragging.** The welcome tour asks which tabs you want and lets you order them by dragging cards (the others make room as you drag; + adds, ✕ removes). The same organizer replaces the arrows in Settings → Appearance → Notch tabs and order.
- 🧹 **Purge menu:** *Free up space* opens Purge, *Review removed apps* opens its leftovers review, and if Purge isn't installed the tab asks whether you want to install it.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates. Choose **Update** or **Not now**, or turn automatic checks off.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
