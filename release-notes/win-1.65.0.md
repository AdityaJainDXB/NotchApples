Notch.apple for Windows 1.65.0

- Hardening: the app's web view now has a content security policy (it loads only its own files and talks only to the services it needs).
- A request that carries a password, token or cookie never follows a redirect to a different site.
- If anything looks broken after updating (a blank panel, missing images), please tell us: this release tightens what the app is allowed to load.

The installer is still named "Notch.apple".
