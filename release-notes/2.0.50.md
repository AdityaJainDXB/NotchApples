**New**
- 🖨 **Bambu Lab tab.** Watch your 3D printer from the notch, straight from the printer on your Wi-Fi: **green** printing, **yellow** paused, **blue** idle, **gray** offline, with the file, a progress bar, time left and live nozzle and bed temperatures. It shows beside the closed notch while a print runs. Add the printer's IP address, access code and serial number (all on its LAN mode screen) in Settings → Bambu Lab. One printer is free; more need Pro.
- 🌡 **Warnings and sounds.** A red glow and a notification if the nozzle is over 300°, the bed over 110°, a heater runs 15° over its target, or the hotend keeps heating with the heater off. A soft sound and a tap when a print pauses, finishes or fails.
- 🔒 **The printer's certificate is remembered** the first time it connects and a different one is refused (Trust new certificate, after a firmware update). The access code is kept in a file only you can read.
- 🚁 **Emergency landing in the Plane game.** In a helicopter press **H**: it levels out, controls the descent, flares and sets down gently, then hands the controls back. A new helicopter panel shows height, climb rate, ground speed, collective and rotor speed.
- ✈️ **Flight Simulator in the menu bar.** Right-click the menu-bar icon to launch the game or pause and resume it.

**Fixes**
- A crash that could happen while a small overlay window (the peek, the command palette, the ruler, full-screen lyrics) resized.
- The app is written **Notch Apple** everywhere.

Windows 1.53.0 BETA gets the Bambu Lab tab and the helicopter emergency landing too.

Install: download the DMG below and drag Notch Apple to Applications, or `brew upgrade --cask notch-apple`.
