**Fixed**
- 📥 **A dragged file no longer slides underneath the notch.** With "Keep the notch visible in full-screen apps" on, the notch sat above the layer macOS draws dragged files on, so it never received a drop. While you drag a file the notch now steps below that layer, takes the drop, and goes back up when you let go.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
