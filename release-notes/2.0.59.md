**Printer Status**
- 🖨️ A clear note: **LAN Mode switches off the printer's cloud features** (the Bambu Handy app, starting or watching prints from outside your home, and print history in Bambu Cloud). Some printers and firmware versions may answer on your network without LAN Mode, so try adding the printer first and switch LAN Mode on only if it cannot connect.

Windows 1.61.0 BETA has the same note.

Install: download the DMG below and drag Notch Apple to Applications, or `brew upgrade --cask notch-apple`.
