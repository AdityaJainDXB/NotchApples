**Improved**
- 💻 **Keep Awake (Lid Closed) asks only when you use it.** The password prompt appears only when you flip the switch. Cancel it and nothing changes and it won't ask again until you flip the switch again; just opening Tools never asks. The low-battery auto-off asks at most once.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates. Choose **Update** or **Skip for now**.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
