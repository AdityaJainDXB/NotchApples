**Fixed**
- 📈 **Claude usage now connects again.** Two things had stopped it working: newer Claude Code versions keep their sign-in under a different keychain name (`Claude Code-credentials-<hash>`), and Anthropic's usage endpoint can be switched off. Notch apple now looks in Claude Code's credentials file and every keychain name, and if the usage endpoint says no, reads your 5-hour and weekly limits from the headers of a one-token reply (a request that costs almost nothing). Approach credited to the open-source [Claude Usage Tracker](https://github.com/hamed-elfayome/Claude-Usage-Tracker) (MIT).
- ⏱ Keychain lookups give up after a few seconds instead of hanging the tab.

Press **Connect** in the Claude usage tab once after updating. If macOS asks, choose Allow.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
