## Notch Apple for Windows 2.2.4 (BETA)

- Friends: a paperclip next to the message box sends a file to a friend or a group (up to 160 KB, so photos, screenshots and documents; not videos). Files are encrypted like messages and kept encrypted on your PC. Click one to show it in File Explorer; it is never opened for you.
- Friends: group chats. Tap + next to Groups, name it and tick friends to add (up to 20 people). Each message is encrypted separately for each member. You see messages only from group members who are also your friends, and the group warns you when some members are not.
- Works with the Mac app (2.2.4): files and group chats go both ways. Untested on real Windows hardware.
