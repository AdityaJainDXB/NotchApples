**Fixed**
- 📤 **PairDrop file transfers now complete.** In 1.34.0 every file transfer failed partway (the connection was closed after the first piece), though codes and chat worked. Found by running real transfers over a loopback connection: a 40 MB file, an empty file, wrong codes and the lockout, chat messages, a silent device, a device that can't save, and an older version's receiver all now pass, and the release pipeline runs that test before it builds.
- 🔗 **Connect to Claude** in the Claude usage tab (real session and weekly limits) is included from 1.34.0: press Connect and allow the macOS prompt.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates. Choose **Update** or **Not now**, or turn automatic checks off.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
