**Fixed**
- 📡 **PairDrop can finally be found.** Until now this Mac only listened for other devices while its **Share** tab was open, so a device sending to it saw nothing unless someone had that tab on screen. PairDrop now runs from the moment Notch apple starts (while the Share module is on), so any device on the Wi-Fi can send it files or start a chat, whatever you have open. A system notification tells you when a file or a message arrives.
- 🪟 **Mac and Windows now talk to each other.** The Windows app has its own PairDrop that speaks exactly the same protocol and finds this Mac over Bonjour. Tested both ways with the real code on each side: files up to 30 MB, an empty file, wrong codes, and chat messages.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates. Choose **Update** or **Skip for now**.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
