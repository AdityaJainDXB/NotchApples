**Changed**
- 🙋 **Updates are a request again, not a demand.** Since 1.34.8 every release forced an update. Now, when a new version comes out, the notch asks the next time you open it, with **Update** or **Skip for now** (it asks again every few opens). Nothing is blocked while you decide.
- 📋 **The update screen shows what is in the update**, in a short scrollable list, so you can decide.
- 🔒 A release is only compulsory when the developer marks it that way; that screen has no skip.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
