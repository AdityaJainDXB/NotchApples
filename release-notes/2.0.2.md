**New**
- ✅ **A To-Do widget on Home, with Quick Add built in.** Type a task at the top and it appears right below: write `call mum tomorrow 3pm !!!` and the date and priority are picked out for you. **High priority is red and pinned to the top** (priority sorting is on by default; the **Priority** button turns it off). Pick High, Medium or Low from the flag, and change it any time. The same list is still in the Notes tab, so your existing tasks, Reminders sync, Things and Todoist are unchanged. The separate Quick Add card is gone from Home.
- 🧩 **Home opens as the widget page for everyone**, with Clipboard, Now Playing and Notes as live cards next to Devices, Notifications and Claude usage. Prefer the old page? Settings → Modules & Layout → Home screen → Classic.

**Fixed**
- 🔗 **"Connect to Claude" now shows what is happening.** On Home the button used to do nothing visible. It now shows a spinner, any error, and the next step. Notch apple steps out of the way so the macOS permission prompt is not hidden behind the notch, and puts itself back with the result.
- 🔑 **Not signed in to Claude Code?** There is now **Sign in with Claude Code**: it opens Claude Code's own sign-in in Terminal and connects by itself when you are done. (Claude's login belongs to Claude Code, so Notch apple does not run its own login window or ask for a key.)

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
