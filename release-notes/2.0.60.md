**Printer Status**
- 🔑 **Watch your Bambu printers without LAN Mode.** Sign in with your Bambu account in Settings → Printer Status, and the printers on the account are added with one click. The Bambu Handy app and the printer's cloud features keep working.
- 🔒 **How it stays safe:** your password goes only to Bambu, over https, and is never saved or logged. Notch Apple keeps just the sign-in token Bambu returns, in an owner-only file, and signing out deletes it. If Bambu asks for an emailed code or an authenticator code, you type it in the same place.
- ⚠️ Bambu has no official way to do this, so it follows what the community has documented and may stop working if Bambu changes its sign-in. This first version has been tested against a simulated Bambu, not a live account: if it does not work for you, LAN Mode still does, and please tell us what you saw.

Windows 1.62.0 BETA has the same sign-in.

Install: download the DMG below and drag Notch Apple to Applications, or `brew upgrade --cask notch-apple`.
