**New**
- 🌑 **⌥A turns the screen brightness to zero, and back.** Press Option+A to black out the built-in display, press it again and the brightness returns to what it was (it is also restored if you quit Notch apple while dark). Needs Accessibility; on by default, switch it off in Settings → Notch → "⌥A turns the screen brightness to zero and back". While on, the key no longer types "å".

**Fixed**
- 🔐 **"Accessibility needed" even though it was already on.** macOS ties that permission to the exact build of the app, so after an update the old switch in System Settings stopped matching and Notch apple kept asking. It now clears the out-of-date entry by itself the first time each new version starts and asks again, so you only switch it on once. If it ever still shows the screen, the new **It's already on: fix it** button does the same thing on demand.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates. Choose **Update** or **Not now**, or turn automatic checks off.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
