**Fixed**
- 🔑 **"Claude didn't accept the saved sign-in" now fixes itself.** The sign-in Claude Code keeps goes out of date unless Claude Code is run, so the usage numbers were refused. When Notch apple finds an expired sign-in it asks Claude Code to renew it (one tiny request, headless), reads the renewed sign-in and connects, all from one press of **Connect to Claude**. If that can't work you get a **Refresh sign-in** button and, failing that, **Sign in again**.

**Updates**
Notch apple tells you when a release like this one is out: a notification, an **Update** button in the notch and a card in Settings → Updates.

Install: download the DMG below and drag Notch apple to Applications, or `brew upgrade --cask notch-apple`.
