# About the licence of the Windows app

The code in this folder (`NotchWindows/`) is released under the **MIT licence** (see `LICENSE`), copyright Aditya Jain.

What the MIT licence covers: the files in this folder, including the flight simulator (`src/js/games/plane-sim.js`), which the Mac app also uses.

What it does not cover:
- the **Notch Apple name and logo**;
- the **Mac app**, the **licence server** (`server/`) and the **website** (`web/`), which keep the repository's source-available licence (`../LICENSE`);
- the **Ultimate modules**, which live in a private repository and are added only to the official builds;
- other people's software, which stays under its own licence (see `THIRD_PARTY.md`).

Pro and Ultimate are unlocked by a key that the licence server checks. Anyone may read, build and change this code under the MIT licence; the official releases and the paid features are what a key pays for.

See `../docs/WINDOWS_SIGNING.md` for how the official Windows builds are signed.
